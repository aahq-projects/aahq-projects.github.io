# RFC-003: Дизайн-Система и UX-Правила

## 1. Визуальное направление
- Стиль: editorial, high-clarity, много воздуха.
- Приоритет: читаемость, иерархия, понятные действия.
- Характер: теплый, авторский, без визуального шума.

## 2. Базовый стек UI
- Astro 5/6
- Tailwind CSS 4
- daisyUI (кастомная тема aahq)

## 3. Токены (база)
- background: #FFFDF9
- surface: #F7F3EE
- text/base-content: #2E2A26
- ink/primary: #171717
- accent/secondary: #C65A3D
- line/base-300: #D8D0C8

## 4. Типографика
- Заголовки: Fraunces.
- Текст интерфейса и абзацы: Instrument Sans.
- Базовый ритм для body: 16px / 1.55.

## 5. Компонентные правила
- Кнопки: обязательные состояния default/hover/focus-visible/disabled/loading.
- Формы: видимый label, явные error-сообщения, не только цвет как индикатор ошибки.
- Карточки: аккуратная глубина, стабильные отступы, адаптивное поведение.

## 6. Accessibility (must-have)
- WCAG 2.2 AA по контрасту и интеракциям.
- Полная клавиатурная навигация.
- Видимый focus на всех интерактивных элементах.
- Touch targets минимум 44x44.
- Учет prefers-reduced-motion.

## 7. Антипаттерны
- Низкий контраст как стилистика.
- Placeholder вместо label.
- Тяжелые декоративные анимации без смысла.
- Разрозненная палитра вне токенов.

## 8. Решение
Использовать этот RFC как визуальный контракт для всех новых страниц и компонентов сайта.
