# RFC-004: Технологический План и Деплой на GitHub Pages

## 1. Цель
Запустить сайт агентства по адресу aahq-projects.github.io как быстрый, статический и легко обновляемый ресурс.

## 2. Базовые решения
- Framework: Astro 5/6.
- Styling: Tailwind CSS 4.
- Components/theme: daisyUI.
- Deployment target: GitHub Pages.

## 3. Минимальная информационная архитектура
- Главная.
- Услуги.
- Кейсы.
- О нас.
- Контакты.

## 4. Контентный минимум для MVP
- Главная по структуре RFC-002.
- 3 сервисных блока с четкими результатами.
- 1-2 кейса или format "кейс в работе".
- Контактный путь: бриф + 30-минутный созвон.

## 5. Нефункциональные требования
- Высокая скорость загрузки.
- Корректная мобильная версия.
- SEO-базис: title, description, OG, canonical, sitemap.
- Техническая доступность по правилам RFC-003.

## 6. Риски
- Недостаток подтвержденных кейсов на старте.
- Смешение RU и EN контуров без явного приоритета.
- Расфокус оффера при расширении списка услуг.

## 7. Контрольные точки
- M1: готова структура страниц и каркас главной.
- M2: готова визуальная система и базовые компоненты.
- M3: собран контент MVP и подключен деплой.
- M4: запущен сайт и зафиксирован backlog итераций.
